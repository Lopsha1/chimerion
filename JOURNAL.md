# Журнал

Состав: BOOKING_CORE. Сеть клубов, ИИ, финансы, PWA и стекло не заказывались.

Навык service-site-director в среде не найден, поэтому постановка взята из текста задания. Astryx не устанавливался: пакета в проекте не было, выдуманный API не подключался. Кнопки — собственный металл на CSS. Иконки Phosphor. MCP браузера на Яндекс Картах открыл пустую вкладку; карточка клуба прочитана через WebFetch, медиа — из публичного Telegram.

Предмет — компьютерный клуб, не детейлинг. Въезд автомобиля не делался.

Цены и железо только из публикации клуба. Standard+ / 2×2 / Solo показаны как зоны, но без выдуманного тарифа не бронируются. Акции не списываются с онлайн-записи.

Проверка пересечений в рабочем приложении — транзакция SQLite. Ограничение Postgres подготовлено и не прогонялось на сервере Postgres. Сквозная публикация в Supabase не проверялась.
