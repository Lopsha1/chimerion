# Chimerion

Сайт компьютерного клуба Chimerion, Уфа, ул. Ахметова, 273. Публичная витрина и серверная запись станций.

## Запуск

Нужен Node.js 22 или новее.

```bash
pnpm install
pnpm dev
```

Если pnpm не стоит, подойдёт `npx pnpm install` и `npx pnpm dev`. Сайт открывается на http://127.0.0.1:5173 , API — на порту 8787.

Кабинет владельца: http://127.0.0.1:5173/admin  
Логин `admin`, пароль `chimerion`, пока не заданы `ADMIN_USER` и `ADMIN_PASSWORD` до первого создания базы. Файл базы — `data/chimerion.sqlite`. Повторный запуск не перезаписывает услуги и фото.

Проверка записи:

```bash
pnpm test
pnpm build
pnpm start
```

`pnpm start` отдаёт собранный сайт и API вместе. Перед этим нужен `pnpm build`, переменная `NODE_ENV=production`.

## Что сохраняется

Запись создаётся транзакцией: сервер заново проверяет свободные станции и не принимает цену из браузера. Повтор того же запроса с тем же ключом возвращает ту же запись. Чужие записи по телефону не открываются: гость управляет визитом по секретной ссылке.

Облачный Supabase к этому проекту не подключён. Файл `supabase/migrations/001_booking_exclusion.sql` — ограничение Postgres на пересечение интервалов, его ещё не применяли к живой базе.
